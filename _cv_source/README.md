# Short public CV download

The website CV remains complete. The downloadable `assets/pdf/Tugnetti_CV.pdf` is intentionally a concise, one-page CV with two columns, four selected professional experiences and two published journal articles. It excludes QFI and other working papers. Public contact information is limited to email, Luxembourg and public profile links. Languages retain their supplied levels without a parenthetical qualification.

`assets/json/resume.json` provides current public facts. `selection.json` defines the concise profile and experience bullets, plus the publication selection rule. `main.tex` is generated by `bin/build_public_cv.py`; edit the inputs, then rebuild instead of editing generated TeX.

## Approved layout exception

The user explicitly requested the JobApplication two-column, one-page template. This approved project renderer therefore controls the PDF layout instead of the generic myPKA report house style. The source was copied from `JobApplication/jobapplication/tools/latex/cv/`, using its `editus-one-page-v1` layout, with a photo-free, public-contact sidebar and dates beneath experience headings. The retained YAAC class credits Christophe Roger and includes its LPPL 1.3c-or-later license notice. Fonts are copied unchanged from that approved template and retain their embedded notices. The source template's attribution identifies YAAC/Christophe Roger and CC BY-SA 4.0; the class's own LPPL notice remains authoritative for that class.

## Rebuild and verify

Requirements: Python 3 with `pypdf` (validated with 6.13.1), plus XeLaTeX and its standard TeX packages for rebuilding. The copied local fonts are required. Poppler's `pdftoppm` supports the visual review.

```sh
python3 -m pip install pypdf==6.13.1
npm run cv:build
npm run cv:check
pdftoppm -scale-to 1600 -png -singlefile assets/pdf/Tugnetti_CV.pdf /tmp/public-cv-preview
```

Inspect the rendered page after every material change. `cv:build` compiles twice, rejects overfull boxes, verifies one page and two-column positions, checks the public content and contact allowlist, then records SHA-256 hashes in `build.json`. `cv:check` needs Python and pypdf but no TeX installation: it checks the generated source, all rendering inputs, PDF hash, page count, column positions and content restrictions. The complete web CV and the short PDF deliberately contain different amounts of information.

Build intermediates are ignored. Previous PDF versions remain recoverable in Git. The former generic house-style source is unused by this renderer.
